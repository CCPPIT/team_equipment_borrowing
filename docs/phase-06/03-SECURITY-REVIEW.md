# 03 — مراجعة الأمان والإعداد
**المصادقة وRBAC خارج النطاق.** اختيار الموظف ليس إثبات هوية؛ أي عميل يستطيع الوصول إلى API يمكنه اختيار موظف. لا نقدّم ذلك كحد أمني لتطبيق عام، ولا نشر ضمن هذه المهمة.

## الفحوص المنفذة
- مصدر المتصفح لا يستورد Prisma أو خدمات backend، ويستخدم `/api` النسبي. Next يتصل بالخلفية خادميًا؛ لا حاجة إلى CORS مفتوح أو wildcard.
- فحص21 ملف static JavaScript أعاد صفر تطابقات لـDATABASE_URL وSYSTEM_DATABASE_URL وpostgresql:// واسم قاعدة QA ورسالة الفشل الداخلية. هذا فحص محدد لا شهادة شاملة.
- UUID وJSON والحقول الزائدة وquantity والموارد المفقودة تُرفض خادميًا بأكواد400/404. لا coercion أو حذف صامت للحقول غير المدعومة.
- أخطاء500 لا تعرض SQL أو Prisma أو رسالة trigger الخاصة، كما تثبت H04/H05/I24. استعلام قفل الصف مربوط المعلمات؛ لا rawUnsafe في المصدر المفحوص.
- ملفات البيئة موثقة؛ المثال الخاص بالويب لا يحتوي DB credentials. لا NEXT_PUBLIC لسر اتصال. ملف.env المحلي بقي ببصمته ويُستبعد من التسليم.

## الاعتماديات: قيد غير محلول
`npm audit --omit=dev`: exit0 و0 نتائج. `npm audit`: **exit1،16 high،0 critical**. مصدر advisory المسجل هو picomatch ReDoS، GHSA-fc5q-39xc-vjpf، وينتقل عبر سلسلة glob وأدوات الاختبار واللينت. العدد16 حزم متأثرة، لا16 ثغرة مستقلة.

آخر picomatch المعروض في registry وقت المراجعة4.0.7 داخل نطاق التأثر. لم نطبق audit fix --force أو خفض Next/Vitest أو ESLint10 غير المتوافق مع peer الحالي لـreact plugin. تحذير انتهاء دعم ESLint9 ظاهر في سجل npm ci. لا ندعي أن الفصل إلى devDependencies يحل الخطر؛ يجب الإفصاح والمتابعة وعدم كشف أدوات التطوير أو تمرير أنماط غير موثوقة إليها.

إضافة ESLint وtypescript-eslint كاعتمادين مباشرين للخلفية توثق استخدام أدوات موجودة أصلًا في الشجرة؛ لا مكتبة runtime جديدة أو major upgrade. جميع نتائج audit ضمن evidence.

## الحدود
لا مجلد.git متاح لتدقيق تاريخ commits؛ نراجع الملفات والحزمة نفسها ولا نختلق دليلًا على تاريخ غير موجود. النصوص مثل secret الوهمية في اختبارات معالجة الأخطاء بيانات اختبار وليست بيانات اعتماد حقيقية.

وكيل TCP ومنفذ التحكم3016 أدوات اختبار loopback خارج منتج API وتُغلق بعد الفحص. إعداد PostgreSQL trust مخصص للتطوير المعزول فقط، لا للإنتاج. لم يُنفذ اختبار اختراق أو تدقيق أمني بشري أو failover أو بنية نشر. الحكم PASS WITH LIMITATIONS مع0 critical مبلغ عنه حاليًا، وليس ادعاء انعدام كل ثغرة محتملة. نتيجة فحص ZIP الفعلي واستبعاد الأسرار في09 و10.
