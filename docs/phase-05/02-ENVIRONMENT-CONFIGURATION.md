# 02 — البيئة والإعداد والتشغيل الآمن
## التقنيات والإعداد الفعلي
Node22.22.2، npm10.8.2، PostgreSQL17.12، Fastify5.12.8، Prisma/client/adapter7.10.1، TypeScript5.9.3، Next16.4.6، React19.3.1، Vitest4.1.12، Playwright1.65.1. npm Workspaces وpackage-lock جذري؛ لا pnpm config لأنه غير مستخدم بقرار Phase02، ولا اعتماديات جديدة في Phase05.

root .env للخلفية محلي وغير مُضمّن بالتسليم. الواجهة تستخدم apps/web/.env.local مستقلًا يحوي API_BASE_URL وWEB_PORT فقط. لا تنسخ root .env إليها. المتصفح يرسل `/api` نسبيًا؛ Next server rewrite يتصل بـFastify، وFastify/Prisma وحده يتصل بقاعدة بيانات التطبيق. قراءات DB المباشرة في **مشغّل الاختبار Node فقط** مراقبة مستقلة وليست كود متصفح.

| الوضع | Next | Fastify | PostgreSQL |
|---|---|---|---|
| التشغيل المحلي الأساسي |3000|3001|5432، قاعدة التطوير |
| Phase05 المعزول |3010|3011 loopback|5545 وكيل اختباري إلى5432، قاعدة مستقلة |
| أداة التحكم الاختبارية |لا تنطبق|3016 loopback، خارج المنتج|قطع/استعادة الوكيل فقط |

لا CORS عام: browser وAPI النسبي من origin واحد؛ اتصال Next بالخلفية server-to-server لا يحتاج CORS. allowedDevOrigins للمعاينة موجود مسبقًا. API_BASE_URL ليس NEXT_PUBLIC ولا يقبل مسارًا أو بيانات اعتماد. rewrite يُثبت في **البناء**؛ تغيير المتغير عند start وحده لا يعيد بناءه.

## إعادة الإنتاج
تتطلب الأوامر PostgreSQL عاملًا وقاعدة جديدة منفصلة وصلاحية ترحيل. المثال اتصال trust محلي معزول فقط، وليس توصية إنتاج أو سرًا؛ استبدله محليًا دون مشاركة كلمة مرور.
```sh
npm ci # تنفيذ الخطوة المحددة على البيئة المحلية المعزولة فقط
npm run prisma:generate # تنفيذ الخطوة المحددة على البيئة المحلية المعزولة فقط
# أنشئ القاعدة إن لم تكن موجودة؛ لا drop ولا reset لقاعدة تطوير
createdb -h 127.0.0.1 -U team_equipment team_equipment_phase05_test # تنفيذ الخطوة المحددة على البيئة المحلية المعزولة فقط
export SYSTEM_DATABASE_URL='postgresql://team_equipment@127.0.0.1:5432/team_equipment_phase05_test?schema=public' # تنفيذ الخطوة المحددة على البيئة المحلية المعزولة فقط
npm run system:migrate # تنفيذ الخطوة المحددة على البيئة المحلية المعزولة فقط
npm run build # تنفيذ الخطوة المحددة على البيئة المحلية المعزولة فقط
API_BASE_URL=http://127.0.0.1:3011 npm run web:build # تنفيذ الخطوة المحددة على البيئة المحلية المعزولة فقط
npm exec -w @team/web -- playwright install --with-deps chromium # تنفيذ الخطوة المحددة على البيئة المحلية المعزولة فقط
npm run system:test # تنفيذ الخطوة المحددة على البيئة المحلية المعزولة فقط
```
أمر createdb يخص قاعدة غير موجودة فقط؛ لا تنفذه ثانية بلا فحص الوجود. اختبار النظام لا ينشئ قاعدة تلقائيًا ولا يرحّلها بصمت؛ يفشل صراحة عند خطأ الإعداد. يجب أن ينتهي اسم SYSTEM_DATABASE_URL بـ`_phase05_test` وأن يختلف عن DATABASE_URL وTEST_DATABASE_URL. system:migrate يتحقق من الاسم الفعلي أيضًا قبل deploy؛ اختُبر رفض الهدف المحمي وغياب الإعداد وخرجا1 كما ينبغي.

مشغل Playwright يبدأ ويغلق backend الحقيقي وNext ووكيلTCP؛ يعمل worker واحد وretries0 لمنع تداخل fixtures وإخفاء flakiness. يحتفظ بالسجلات التاريخية داخل قاعدة الاختبار عند السيناريو ثم يعيد fixtures بين السيناريوهات. لا يُشغّل ذلك على قاعدة حقيقية حتى لو غُير اسمها؛ موافقة متغير البيئة لا تعفي المشغّل من اختيار الهدف الصحيح.

## التشغيل العادي بعد الاختبار
```sh
# أوقف معاينة Next الحالية قبل بناء جديد؛ .next مشترك ولا تشغّل بناءين متوازيين
API_BASE_URL=http://127.0.0.1:3001 npm run web:build # تنفيذ الخطوة المحددة على البيئة المحلية المعزولة فقط
npm run api:start # تنفيذ الخطوة المحددة على البيئة المحلية المعزولة فقط
npm run web:start # تنفيذ الخطوة المحددة على البيئة المحلية المعزولة فقط
```
آخر بناء في الجلسة أعيد إلىAPI3001، والمعاينة المحلية3000 نجحت بقراءات فقط. بيئة الاختبار/أدوات القطع أُغلقت. ليست هذه عملية نشر.

## الأمثلة والأسرار
أضيف SYSTEM_DATABASE_URL إلى .env.example الآمن، واستثناء `.env.*.example` إلىgitignore. .env الحقيقي ظل ببصمته، لا .git في المستودع لتدقيق التاريخ. فُحصت21 حزمة JS static بحثًا عن DATABASE_URL وSYSTEM_DATABASE_URL وpostgresql:// واسم قاعدة Phase05 ورسالة DB الخاصة:0 تطابق. هذا فحص محدد وليس شهادة secret scanning شاملة لكل تاريخ غير متاح. الأرشيف لا يضم ملفات env المحلية أو قواعد ثنائية أو node_modules.
