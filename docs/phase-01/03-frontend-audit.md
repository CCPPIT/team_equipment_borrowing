## مطابقة الوظائف
جميع FR-01 إلى FR-10 غير منفذة. يجب لاحقًا إظهار الموظفين والمعدات والمتاح واستعارة الموظف الحالي، وإتاحة Borrow وReturn، وإظهار التحميل والأخطاء، وتحديث المتاح والحالة بعد النجاح، ومنع تكرار الإرسال أثناء التنفيذ. إعادة الجلب مقبولة دون تحديث كامل للصفحة.

## مخاطر الحالة التي ستحتاج تحققًا
- تأخر استجابة A بعد اختيار B لا يعرض بيانات A باعتبارها B.
- Return يبقى ممكنًا للاستعارة النشطة حتى عندما المتاح صفر.
- تعطيل الزر لا يعوض فحص الخلفية للسباق والتكرار.
- فشل إعادة جلب البيانات بعد نجاح العملية لا يُعرض كأنه فشل العملية المثبتة.
- لا ترسل mutation دون employeeId صالح ولا تكرر Borrow تلقائيًا عند غموض نتيجة الشبكة.

لا واجهة لتشغيلها أو اختبارات عرض لتنفيذها؛ كل ادعاء قدرة فعلية Not Verified.
