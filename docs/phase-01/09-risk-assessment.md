# 09 — سجل المخاطر التقنية

التقييم نوعي تقديري وليس قياسًا من تطبيق عامل. الاحتمال: منخفض/متوسط/مرتفع. الأثر: متوسط/مرتفع/حرج. Severity أولوية هندسية نوعية؛ الاحتمال المرتفع مع أثر حرج «حرج»، والأثر المرتفع أو الحرج مع احتمال متوسط «مرتفع». لا تدعي الأرقام أداءً أو إحصاءات.

| Risk ID | الوصف | الاحتمال | الأثر | Severity | استراتيجية التخفيف المشروطة |
|---|---|---|---|---|---|
| R-01 | Database Race Conditions على آخر وحدة | مرتفع | حرج | حرج | تصميم transaction وحماية DB واختبارات overlap حقيقية |
| R-02 | Duplicate Active Loans | مرتفع | حرج | حرج | فرادة تخص النشط فقط مع فحص محمي؛ TEST-01/06 |
| R-03 | Incorrect Stock Updates | متوسط | حرج | مرتفع | دلتا وحدة واحدة وثوابت مصالحة المخزون والنشط |
| R-04 | Repeated Returns تضاعف الرصيد | مرتفع | حرج | حرج | انتقال حالة مشروط ومحمي وزيادة واحدة؛ TEST-03/06 |
| R-05 | Inconsistent Transactions بسبب كتابة جزئية | متوسط | حرج | مرتفع | معاملة واحدة وحقن فشل بين الكتابتين؛ TEST-05 |
| R-06 | Invalid Frontend State عند تبديل الموظف | متوسط | مرتفع | مرتفع | ربط الطلب بالموظف وتجاهل الردود القديمة واختبارها |
| R-07 | API Error Handling غير متسق أو يكشف تفاصيل | متوسط | مرتفع | مرتفع | عقد أخطاء وتصنيف وتغطية API وعدم كشف stack/credentials |
| R-08 | Environment Configuration غير جاهز | مرتفع | مرتفع | مرتفع | توافق إصدارات موثق وإعداد محلي قابل للتكرار لاحقًا |
| R-09 | Missing Tests تخفي أخطاء القواعد | مرتفع | حرج | حرج | قاعدة اختبار منفصلة وتغطية الحالات الست قبل التسليم |
| R-10 | اختلاف ترقيم قواعد العمل يربك التنفيذ | مرتفع | مرتفع | مرتفع | استخدام P00/P01 ومصفوفة المطابقة دون تغيير المصدر |
| R-11 | اعتبار طلب التدقيق اعتمادًا ضمنيًا لكل Phase 00 | متوسط | مرتفع | مرتفع | وقف القرارات النهائية وطلب اعتماد واضح |
| R-12 | unique عام يمنع التاريخ وإعادة الاستعارة | متوسط | حرج | مرتفع | مراجعة الفرادة النشطة والاختبار المتكرر |
| R-13 | اختبار تنظيف يغير بيانات حقيقية | متوسط | حرج | مرتفع | تحقق هدف DB وعزل fixtures؛ لا تغييرات قاعدة الآن |
| R-14 | تعليقات كل سطر تفسد JSON أو الصيغ الحساسة | متوسط | مرتفع | مرتفع | توضيح الأسطر القابلة للتعليق وتوثيق الاستثناءات قبل الكود |

غياب الكود والبيئة ليس فشلًا في تنفيذ قائم؛ لكنه يمنع إثبات التشغيل والتوافق. لا نعالج المخاطر بإضافة queues أو distributed locks أو بنية غير مطلوبة. التخفيف هنا مقترح وليس إجراء مطبقًا.
