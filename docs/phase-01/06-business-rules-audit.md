# 06 — تدقيق قواعد العمل ومطابقة المعرّفات

## اختلاف مهم يجب عدم إخفائه
قائمة Phase 01 أعادت ترقيم قواعد Phase 00 وأضافت نصًا صريحًا لاستعارة أنواع مختلفة. نستخدم **P01-BR-xx** هنا لتمييز المصدر، ولا نغير الملفات القديمة أو معرّفاتها. القاعدة الجديدة توضيح متسق مع قيد «لكل نوع» وليست دورًا أو سير عمل جديدًا. منع زيادة المخزون بالإرجاع المتكرر ما زال إلزاميًا ولو لم يظهر كبند مستقل في قائمة Phase 01.

الفهم: **نعم** لكل الصفوف. الدعم الحالي: **مفاهيمي فقط / التنفيذ Missing** لكل الصفوف. أماكن التطبيق التالية مستهدفة بعد الاعتماد وليست وصفًا لكود موجود.
